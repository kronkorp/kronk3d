# Robot

The player model of the Godot 3D platformer demo, unchanged:
https://github.com/godotengine/godot-demo-projects/blob/master/3d/platformer/player/player.glb
(commit b761b4cd5718a7118f2c95eb55f181d0a5f004f1).

27 joints, two untextured materials, and the clips `idle`, `walk`, `run`, `jump`, `falling`,
`shooting`, `shooting_standing` and `RESET`.
